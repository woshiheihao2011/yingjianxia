1. 核心交易主流程

买家从浏览到收货的完整交易链路，平台担保贯穿全流程。涉及页面：index → browse/search → product → cart → orders → logistics → reviews

2. 商品发布与验机流程

卖家发布商品的完整链路：填写信息 → 同意验机 → 提交审核 → 平台验机 → 生成报告 → 上架在售。涉及页面：sell → listings → product

3. 售后退款流程

买家发起售后后的三种处理路径：仅退款、退货退款（含卖家拒绝→平台仲裁）、换货。涉及页面：aftersales → orders → tickets

4. 资金托管流转流程

担保交易的资金流转全链路：买家付款 → 平台冻结 → 确认收货放款 / 售后退款。涉及页面：cart → wallet → transactions → aftersales

5. 流程节点汇总表

四条核心业务流程的关键节点、参与角色与状态流转一览
