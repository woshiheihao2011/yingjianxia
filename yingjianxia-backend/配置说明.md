## 一、项目总览


## 三、环境准备

### 3.1 前置依赖

| 组件             | 版本   | 说明                 |
| -------------- | ---- | ------------------ |
| JDK            | 17+  | Spring Boot 3 最低要求 |
| Maven          | 3.9+ | 多模块编译              |
| Docker         | 24+  | 中间件容器化             |
| Docker Compose | v2+  | 编排中间件              |

### 3.2 一键启动中间件

```bash
# 进入项目根目录
cd c:\Users\DELL\Desktop\trae\yingjianxia-backend

# 启动全部中间件 (MySQL/Redis/Nacos/RocketMQ/Sentinel)
docker-compose -f docker-compose-env.yml up -d

# 检查容器状态
docker-compose -f docker-compose-env.yml ps
```

中间件启动后访问地址：

- **Nacos 控制台**: <http://localhost:8848/nacos> (账号: nacos / 密码: nacos)

- **Sentinel 控制台**: <http://localhost:8858> (账号: sentinel / 密码: sentinel)

- **RocketMQ 控制台**: <http://localhost:19876>

- **MySQL**: localhost:3306 (root / 123456)

- **Redis**: localhost:6379

### 3.3 初始化数据库

MySQL 容器启动时会自动执行 `scripts/init-databases.sql` 创建全部 12 个数据库。

如需手动执行：

```bash
mysql -h 127.0.0.1 -u root -p123456 < scripts/init-databases.sql
```

然后依次执行业务表 SQL：

```bash
mysql -h 127.0.0.1 -u root -p123456 db_user < ../hardware-architecture-design/sql/01_db_user.sql
mysql -h 127.0.0.1 -u root -p123456 db_product < ../hardware-architecture-design/sql/02_db_product.sql
mysql -h 127.0.0.1 -u root -p123456 db_inspection < ../hardware-architecture-design/sql/03_db_inspection.sql
mysql -h 127.0.0.1 -u root -p123456 db_order < ../hardware-architecture-design/sql/04_db_order.sql
mysql -h 127.0.0.1 -u root -p123456 db_escrow < ../hardware-architecture-design/sql/05_db_escrow.sql
```

### 3.4 Nacos 配置导入

在 Nacos 控制台创建以下配置（Data ID → Group: YINGJIANXIA\_GROUP）：

| Data ID              | 说明               |
| -------------------- | ---------------- |
| gateway-service.yaml | 网关路由/限流规则        |
| user-service.yaml    | 用户服务配置           |
| product-service.yaml | 商品服务配置           |
| ... 其余服务同理           | 每个服务对应一个 Data ID |

> 开发环境下，bootstrap.yml 中的 `${NACOS_SERVER}` 等环境变量有默认值，Nacos 中可不配置，服务会使用本地 bootstrap.yml 中的 dev profile 配置。

## 四、编译与启动

### 4.1 全量编译

```bash
cd c:\Users\DELL\Desktop\trae\yingjianxia-backend
mvn clean install -DskipTests -T 4
```

### 4.2 单模块编译

```bash
# 只编译 order-service 及其依赖
mvn -pl order-service -am clean install -DskipTests
```

### 4.3 全量启动 (PowerShell)

```powershell
cd c:\Users\DELL\Desktop\trae\yingjianxia-backend

# 1. 加载环境变量
. .\scripts\env.ps1

# 2. 编译并启动
.\scripts\start-all.ps1 -Build

# 或跳过编译（已编译过）
.\scripts\start-all.ps1

# 只启动部分服务
.\scripts\start-all.ps1 -Only "user-service,product-service"

# 跳过网关
.\scripts\start-all.ps1 -SkipGateway
```

### 4.4 全量启动 (Batch)

```cmd
cd c:\Users\DELL\Desktop\trae\yingjianxia-backend
scripts\start-all.bat
```

### 4.5 单服务启动

```powershell
.\scripts\start-single.ps1 -Service order-service
```

### 4.6 停止所有服务

```powershell
.\scripts\stop-all.ps1
```

### 4.7 启动顺序（按依赖）

```
优先级 1: gateway-service        (网关先行)
优先级 2: user-service           (认证基础)
         evaluation-service
优先级 3: product-service         (商品基础)
         inspection-service
         audit-service
优先级 4: order-service           (交易核心)
         escrow-service
         payment-service
         marketing-service
优先级 5: logistics-service       (履约)
         aftersales-service
         message-service
优先级 6: community-service       (平台支撑)
         support-service
         risk-service
```

> `start-all.ps1` 已按此顺序排列，每服务间隔 3 秒启动。

## 七、生产环境注意事项

1. **JWT 密钥**: 生产环境必须更换 JWT\_SECRET，建议 256 位随机字符串
2. **MySQL 密码**: 修改 root 密码，创建独立业务账号
3. **Redis 密码**: 生产环境必须设置 REDIS\_PWD
4. **Nacos 认证**: 修改 Nacos 默认密码，关闭 guest 访问
5. **内部密钥**: 更换 INTERNAL\_SECRET 为强随机值
6. **HTTPS**: 网关层配置 SSL 证书
7. **日志**: 生产环境将 log level 调为 INFO/WARN，接入 ELK
8. **JVM**: 生产环境建议 `-Xms1g -Xmx2g -XX:+UseG1GC -XX:MaxGCPauseMillis=200`
9. **HikariCP**: 生产环境 maximum-pool-size 建议按 CPU\*2+IO 调优
10. **ShardingSphere**: 分表配置需在生产 bootstrap.yml 中启用（5张大表: orders/transactions/messages/logistics\_tracks/points\_records）
