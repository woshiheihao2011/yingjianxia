1. 需求背景

电脑硬件二手交易长期存在三大痛点：信任缺失、资金安全无保障、售后扯皮。闲鱼等综合二手平台缺乏针对硬件的专业验机能力，买家无法判断 GPU 是否矿卡、CPU 是否超频缩缸、SSD 寿命剩余多少。卖家则面临恶意退款、资金到账慢等问题。

硬件侠定位为垂直于电脑配件的二手交易平台，通过"平台验机 + 担保交易 + 7天退换"三大核心机制，在买卖双方之间建立信任桥梁。平台面向 PC 发烧友、装机用户、数码极客等群体，覆盖显卡、CPU、主板、内存、硬盘、散热器六大品类。

核心差异化：不是"又一个闲鱼"，而是"有验机报告的硬件二手平台"。验机报告是平台的护城河 —— 每件商品经过 12 项专业检测（外观、风扇、GPU核心、显存、压力测试、温度、接口等），生成可查看的检测报告，买家买得明白，卖家卖得安心。

2. 需求目标

目标维度当前状态目标衡量方式
信任建立无专业验机渠道每件商品附带 12 项验机报告验机覆盖率 ≥ 95%
资金安全私下交易无保障平台担保交易，确认收货后放款担保交易占比 ≥ 90%
售后体验纠纷无人仲裁7 天无理由退换 + 平台仲裁纠纷解决率 ≥ 98%
卖家效率手动管理、无数据卖家数据中心 + 库存预警 + 自动客服卖家月均发布时长 ≤ 10 分钟

3. 用户角色定义

平台采用 C2C 模式，买卖双方身份可自由切换。同一个账号既可以是买家也可以是卖家，核心交易页面（订单、评价、售后）均支持"我是买家 / 我是卖家"双角色切换。

买家

硬件买家

寻找性价比高的二手配件，关注成色、保修、验机报告。核心诉求：买得明白、买得放心、坏了能退。

使用频率：中高频；技术能力：中高级

卖家

硬件卖家

出售闲置或升级换下来的配件，关注发布效率、资金到账速度、店铺运营。核心诉求：卖得快、钱到得快、管得省心。

使用频率：高频；技术能力：高级

平台

平台运营

审核商品发布、处理纠纷仲裁、管理公告与活动。核心诉求：平台秩序、信任生态。

使用频率：日常；技术能力：中级

平台

客服

处理工单、快捷回复、协助纠纷处理。核心诉求：高效响应、标准化话术。

使用频率：日常；技术能力：中级

5. 功能需求详情

以下按功能模块组织，每个模块包含功能概述、页面布局、业务逻辑、关键字段与状态流转。涉及页面以 page.html 标注。

1

认证与账户

auth.html profile.html

页面布局

认证页面采用居中卡片布局，包含三个 Tab（登录 / 注册 / 找回密码），通过 JS 切换表单面板。个人中心页面包含用户信息头（头像、昵称、简介、认证标签）、统计卡片（信用分、成交数、月收入）、三个 Tab 面板（我的发布 / 我的订单 / 消息中心）。

业务逻辑

登录注册流程：用户通过手机号或邮箱注册，注册需获取验证码（60 秒倒计时防刷），设置密码后需勾选用户协议。登录支持密码登录和第三方登录（微信 / QQ / 支付宝）。找回密码流程与注册类似，验证身份后重置密码。

个人中心：展示用户身份信息与认证状态（实名认证、优质卖家标签）。统计卡片实时反映信用分（基于历史交易和评价计算）、成交笔数、本月收入。三个 Tab 分别管理用户的发布商品（含审核中/在售/已售状态）、订单（买家视角）、站内消息（含未读红点提示）。消息支持"全部标记为已读"操作。

字段规则

字段类型必填规则
手机号/邮箱文本是手机号 11 位数字 / 邮箱格式校验
验证码数字是6 位，60 秒倒计时，有效期 5 分钟
密码文本是8-20 位，含字母和数字
用户协议复选框是注册必须勾选
信用分数值-系统计算，0-5 分，保留一位小数

商品浏览与搜索

index.html browse.html search.html

页面布局

首页包含 Hero 搜索区、热门分类（6 类卡片：显卡/CPU/主板/内存/硬盘/散热器）、精选好物（3 列商品卡）、平台保障（验机/担保/退换）、CTA 行动号召、Footer。

浏览页采用左右两栏布局：左侧筛选面板（分类复选框、成色单选、价格区间输入），右侧商品网格（1/2/3 列响应式）。顶部显示商品总数与价格排序下拉。移动端筛选折叠为 <details> 手风琴。

搜索页顶部为关键词标签（可清除）、结果计数、横向筛选栏（分类/价格/成色/所在地/排序下拉）、已选标签行（可逐个移除或清除全部）。支持网格/列表视图切换，列表视图展示更宽的图片和卖家评分。包含空状态（无结果时显示清除筛选按钮）。

业务逻辑

筛选与排序：分类支持多选（显卡、CPU、主板、内存、硬盘、散热器），成色单选（全新/99新/9成新/战损版），价格区间为 min-max 数字输入。排序选项包括价格升降、最新发布、热度优先、新旧程度。搜索结果页的所在地筛选支持北京、上海、广州、深圳、成都、杭州。

商品卡信息：每张商品卡包含图片（4:3）、标题（2 行截断）、成色徽章（颜色编码）、价格（大号主色）、位置（地图图标）、发布时间、卖家名称。搜索结果额外显示卖家评分（星级）。

分类跳转：首页热门分类卡点击后跳转至 browse.html?category=gpu，携带分类参数自动筛选。

商品详情与购买

product.html cart.html

页面布局

商品详情页采用 60/40 上部布局 + 下方详情区。左侧为图片画廊（主图 + 4 张缩略图，点击切换），右侧为商品信息（成色徽章、标题、商品 ID、价格卡含原价划线、购买时间/保修/箱说/拆修信息网格、卖家卡、立即购买/联系卖家按钮、浏览/想要/发布时间统计）。下方分左右两栏：左侧为规格参数表 + 卖家描述，右侧为验机报告（12 项检测全部通过提示 + 评级 + 检测清单 + 查看完整报告按钮）。

购物车页采用左右两栏：左侧为商品列表（每项含复选框、图片、标题、规格、价格、数量加减控件、删除按钮），右侧为结算侧栏（收货地址、订单摘要、支付方式、提交订单按钮）。

业务逻辑

验机报告（核心差异化功能）：每件商品经过 12 项专业检测，在商品详情页展示检测清单，包含外观无划痕磕碰、风扇运转正常、GPU核心无维修、显存颗粒正常、3DMark 压力测试（通过率 99.2%）、温度稳定性、接口输出测试等。验机报告评级为"优"，买家可查看完整报告。验机报告由平台检测中心出具，不可由卖家编辑。

购买流程：用户点击"立即购买"跳转购物车，或加入购物车后统一结算。购物车支持全选/单选、数量增减、单件删除。结算侧栏显示收货地址（可切换/新增）、订单摘要（商品总额、运费、优惠、应付合计）、支付方式（余额支付/微信/支付宝）。提交订单后进入担保交易流程，货款由平台托管。

联系卖家：点击"联系卖家"跳转至 messages.html，自动创建或打开与该卖家的会话，并在聊天头部嵌入当前商品卡片。

订单管理

orders.html reviews.html

页面布局

订单中心顶部为角色切换器（我是买家 / 我是卖家），下方为状态筛选 Tab（全部/待付款/待发货/待收货/已完成/售后中）和搜索栏（订单号/商品名称 + 时间范围 + 排序）。订单卡片包含商品图片、标题、卖家/买家名称、单价 × 数量、总价、操作按钮组。包含空状态提示和分页。

评价管理同样支持买卖双角色切换。买家侧含"待评价/已评价"两个 Tab，待评价列表有"去评价"按钮，已评价展示星级、标签、评论文本、图片、卖家回复。卖家侧展示评分统计（综合评分、好评率、累计评价）和收到的评价列表，支持"回复评价"。

业务逻辑

订单状态流转（买家视角）：

待付款 → 待发货 → 待收货 → 已完成 → 售后中

每个状态对应的操作按钮：待付款（付款/取消订单）、待发货（提醒发货/查看详情）、待收货（查看物流/确认收货）、已完成（评价/申请售后）、售后中（查看进度/联系客服）。卖家视角：待发货（去发货）、已完成（查看详情）。

评价规则：评价为 5 星制，可选标签（物流快/成色好/沟通顺畅/包装严实/描述相符），支持图文评价和匿名评价。买家可追评。卖家可回复评价。评价数据影响卖家信用分和好评率。

5

售后与退款

aftersales.html

页面布局

页面分为两个 Tab："申请售后"和"售后进度"。申请售后 Tab 采用左右两栏：左侧为申请表单（选择订单商品 → 售后类型 → 申请原因 → 问题描述 → 上传凭证 → 退款金额），右侧为售后规则提示和帮助入口。售后进度 Tab 包含角色切换器、状态筛选 Tab 和进度卡片列表（含垂直时间线）。

业务逻辑

售后类型：仅退款、退货退款、换货三种。申请原因包括：商品与描述不符、商品存在质量问题、配件缺失/漏发、疑似假冒/非正品、运输途中损坏、买错了/不需要了、其他原因。退款金额不可超过订单实付金额。凭证支持最多 6 张图片（JPG/PNG，单张最大 10MB）。

售后规则：7 天内可申请退换，退货需保持商品完好，平台 1-3 个工作日审核。审核通过后，退货退款/换货需买家寄回商品，仅退款直接进入退款流程。卖家可同意或拒绝售后申请，拒绝时需提供理由。平台可介入仲裁。

售后状态流转

审核中 → 已通过 → 待退货 → 已完成
审核中 → 已拒绝

消息与社区

messages.html community.html

页面布局

消息页面采用全屏布局（calc(100vh - 64px)），左侧为会话列表（320px 宽，含头像、昵称、最后消息、时间、未读徽章），右侧为聊天详情（头部含联系人信息和嵌入的商品卡、消息气泡区、底部输入区含图片按钮和发送按钮）。移动端通过返回按钮在列表/详情间切换。

社区页面包含 Hero 搜索区（含统计数据：攻略数/达人数/讨论数）、粘性分类 Tab（全部/装机指南/避坑攻略/硬件评测/二手验机/问答互助/晒单）、左侧主内容区（精选攻略卡片 + 最新帖子列表 + 分页 + 发帖表单）、右侧边栏（热门话题排行 + 社区达人榜 + 最新活动）。

业务逻辑

消息私聊：会话列表按最后消息时间排序，未读消息以红色数字徽章标记。聊天支持文本和图片消息，消息气泡区分左右（对方左/自己右），按日期分组显示。聊天头部嵌入商品卡片，点击可跳转商品详情。从商品详情页"联系卖家"进入时自动定位或创建对应会话。

社区：帖子分类为 6 类，支持图文发布（标题 + 分类下拉 + 正文 + 图片拖拽上传）。帖子卡片显示作者、时间、分类标签、标题、摘要、点赞/评论/浏览统计。支持最新/最热排序。侧边栏热门话题为实时排行，达人榜展示等级（Lv.7-9）和发布数/获赞数。活动支持进行中/报名中/已结束三种状态。

页面布局

单列表单页面。从上到下依次为：图片上传区（拖拽上传，最多 9 张，单张 10MB）、商品详情表单（标题/分类/价格/成色/原价/购买渠道/箱说全复选框/商品描述）、验机报告同意项（复选框：已上传或同意平台验机报告）、提交按钮。

业务逻辑

信任体系三大支柱：

  • 平台验机：每件商品经 12 项专业检测，生成验机报告，买家可在商品详情页查看完整报告。验机流程：下单 → 寄送检测中心 → 专业检测 → 生成报告 → 签收。
  • 担保交易：平台托管货款，买家确认收货后放款给卖家。担保交易金额累计 ¥9.8 亿。
  • 7 天退换：到手 7 天内与描述不符可申请退换，平台 1-3 工作日审核，纠纷解决率 98.7%。

举报机制：用户可举报商品违规、虚假交易、诈骗、盗图、恶意辱骂等行为。需选择被举报对象类型（商品/用户/订单）、填写对象编号或链接、选择举报原因、描述详情并上传证据图片（最多 6 张）。支持匿名举报。举报记录显示受理中/已处理/待处理状态及处理结果。

6. 非功能需求

性能

指标要求
首屏加载≤ 2 秒（4G 网络）
页面切换≤ 500ms（SPA 路由）
搜索响应≤ 800ms（含筛选）
图片加载懒加载 + WebP 格式 + CDN 加速
消息延迟≤ 2 秒（WebSocket 推送）

安全

  • 实名认证：卖家必须完成实名认证方可发布商品
  • 支付安全：支付密码 + 短信验证双重验证，单笔/单日限额控制
  • 数据加密：HTTPS 全站加密，敏感信息（手机号/地址）脱敏展示
  • 防欺诈：交易风控系统，异常行为检测（批量发布/频繁退款等）
  • 内容审核：商品发布人工/机器审核，违规商品自动下架

可用性

  • 响应式设计：适配桌面（≥1024px）、平板（768-1023px）、移动端（≤767px）
  • 深色主题：全站深色科技风，与硬件发烧友审美匹配
  • 无障碍：键盘导航、焦点环、aria 标签、语义化 HTML
  • 离线提示：网络断开时显示友好提示，不丢失已输入数据

兼容性

  • 浏览器：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
  • 移动端：iOS 14+、Android 10+（响应式 Web，非原生 App）
  • 技术栈：Tailwind CSS v4 + Lucide Icons + 原生 JS（无重框架依赖）
