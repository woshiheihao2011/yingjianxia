P0-01 买家/审核账号无法登录 P0 阻断
买家账号 13900001234 / 密码 12345678 登录时提示"账号或密码错误"。审核账号与之相同。该问题直接阻断买家侧全部需登录功能（订单、售后、个人中心、消息等），是最优先修复项。
影响范围: 买家侧全链路 可能原因: 数据库中未创建该测试账号 / 密码加密不一致 / 账号状态异常
P0-02 卖家管理后台全部不可用（shopId 参数类型错误） P0 阻断
/seller 返回404，/seller/products、/seller/inventory、/seller/orders、/seller/shipping、/seller/dashboard、/seller/wallet、/seller/settings、/seller/marketing 均报"店铺信息加载失败 — 参数 shopId 类型错误，期望值 Long"。卖家管理后台完全瘫痪，影响商品管理、库存、订单、发货、财务等8个核心模块。
影响范围: 卖家侧8个管理页面 可能原因: 前端传递 shopId 为 String 类型，后端接口期望 Long 类型，类型转换缺失
错误信息: "参数 shopId 类型错误，期望值 Long"
P0-03 商品详情页数据严重异常 P0 阻断
/product/1 页面价格显示 ¥0、商品图片显示"暂无图片"、卖家信息显示"未知店铺"、无验机报告模块。商品详情是交易链路的核心页面，数据异常将导致买家无法做出购买决策。购物车页面同样受影响（商品状态"加载中"、价格¥0、店铺"未知店铺"）。
影响范围: 商品详情、购物车、交易全链路 可能原因: 商品数据未正确关联店铺信息 / 图片URL字段为空 / 价格字段默认值0未覆盖
P1-01 搜索功能返回0条结果 P1 严重
/search?q=显卡 搜索页面正常加载但返回0条结果。首页已展示有显卡类目商品，说明商品数据存在，但搜索接口未正确匹配。搜索是买家找货的核心入口，需排查搜索服务的索引和查询逻辑。
影响范围: 买家搜索 可能原因: ES索引未建立 / 搜索关键词匹配逻辑有误 / 搜索接口连接的服务异常
P1-02 分类过滤不生效 P1 严重
/browse?category=cpu、/browse?category=gpu、/browse?category=motherboard、/browse?category=memory、/browse?category=storage 均显示相同的15件商品，未按分类参数过滤。分类导航点击可跳转但结果不区分品类，买家无法精准找货。
影响范围: 买家分类浏览 可能原因: 前端未将 category 参数传递给后端 / 后端查询未加分类过滤条件 / 分类映射表缺失
P1-03 商品图片加载异常 P1 严重
部分商品图片显示为"??????"（乱码/编码问题），收藏列表中商品图片显示"无图"，商品详情页图片显示"暂无图片"。图片是商品展示的关键元素，缺失严重影响用户体验。
影响范围: 商品列表、商品详情、收藏列表 可能原因: 图片URL字段为空或格式错误 / 图片服务器未启动 / CDN配置有误 / 字符编码问题
P1-04 验机报告模块缺失 P1 严重
商品详情页无验机报告模块。根据PRD需求，验机报告是硬件侠平台的核心差异化功能，包含12项完整性检查、等级验证和overallResult算法。/inspection 和 /admin/inspection 页面均返回404，验机相关业务线完全缺失。
影响范围: 商品详情、验机流程、审核流程 可能原因: 验机相关前端页面未开发 / 验机服务未对接 / 验机报告数据模型未落地
P2-01 多个页面路由404 P2 功能缺失
以下页面路由均不存在，返回404：
  • 买家侧：/category（分类入口）、/profile/address（收货地址）、/profile/reviews（评价管理）、/points（积分）
  • 审核侧：/admin（管理后台）、/review（审核入口）、/admin/products（商品审核）、/admin/inspection（验机审核）、/admin/orders（订单管理）、/admin/users（用户管理）、/inspection（验机页面）
  • 平台支撑：/about（关于我们）、/notice（公告）、/ticket（工单）、/coupon（优惠券）
共计15个页面路由未注册，需确认是前端路由未配置还是页面组件未开发。
影响范围: 15个页面 可能原因: 前端路由表未注册对应路径 / 页面组件尚未开发
P2-02 卖家中心入口缺失 P2 功能缺失
/seller 返回404，且首页导航栏未发现卖家中心入口。卖家登录后无统一的管理工作台页面，影响卖家操作体验。需开发卖家中心首页并添加导航入口。
影响范围: 卖家侧导航 可能原因: 卖家中心页面组件未开发 / 路由路径不一致（可能应为 /seller/dashboard 而非 /seller）
P2-03 分类页面面包屑异常 P2 UI缺陷
主板分类（/browse?category=motherboard）和内存分类（/browse?category=memory）页面面包屑显示异常，未正确显示对应分类名称。分类筛选器高亮状态也不正确。
影响范围: 分类浏览页面 可能原因: 分类名称映射表缺失 / 面包屑组件未正确读取当前分类参数
P2-04 审核账号与买家账号相同 P2 需求确认
用户提供的审核账号和买家账号均为 13900001234，无法区分角色。需确认审核账号是否应为不同的手机号，或该账号是否在数据库中被赋予了审核角色权限。
影响范围: 审核侧全链路 建议: 提供独立的审核账号 / 确认账号角色权限配置
P3-01 审核中心无待审核数据 P3 数据问题
审核中心（/audit）页面正常加载，但显示"暂无待审核记录"。虽有商品审核/帖子审核/举报处理/提现审核四个模块入口，但无实际审核数据。需确认是否有待审核的商品或内容。
影响范围: 审核流程验证 建议: 发布商品后触发审核流程，验证审核中心数据流转
